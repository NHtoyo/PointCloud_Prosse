# 利用ガイド

## 起動と点群読込

1. Unity 6000.4.7f1でプロジェクトを開き、`VRTestScene`を再生します。
2. PointCloudDataフォルダ内のPLYを選択します。アプリはヘッダーとXYZを検証し、読込中は進捗表示を出します。
3. 読込をキャンセルすると、現在表示中の点群は差し替えません。破損・未対応PLYはエラー詳細を確認し、元ファイルを修正してください。

PLYのvertexはXYZが必須です。ASCII、binary little-endian、binary big-endianとスカラーpropertyを扱います。vertexより前にデータを持つelement、およびvertex list propertyは未対応として拒否されます。上限を超えた場合は先頭から`maxPointsToLoad`点を読み込みます。

## 注釈

1. 左側パネルで選択ツールとクラスを選びます。
2. 点を選択し、適用操作を行います。
3. 元に戻す/やり直すは現在の点群内の履歴です。点群を切り替えると履歴は消去されます。
4. エクスポート前に選択数・出力先・対象モードを確認します。

## C2C距離

基準点群と位置合わせ対象を設定してC2C距離計算を実行します。距離計算は表示変換後の座標を比較し、既存のmm表示を保ちます。処理はキャンセル可能です。C2C結果は各対象点に最も近い基準点までの厳密な距離です。

## Python機能

Python機能の初回使用時は、システムにPythonが必要です。Pythonがない場合、アプリはシステム全体へのインストールを行わず案内を表示します。依存パッケージは`python_backend/.venv`に入ります。ネットワーク接続が必要になる場合があります。

## 注意

茎径・球径などの研究結果は、既知寸法の実測検証を別途行ってください。操作UIは本監査時に複数解像度での実表示確認をしていません。
