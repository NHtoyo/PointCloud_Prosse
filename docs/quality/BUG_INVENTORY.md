# バグ一覧

この監査で特定した問題と対応状況です。優先度は影響度で、`P0`は結果の誤り、`P1`はデータ完全性・安定性・主要操作、`P2`は未検証の互換性や品質リスクです。

| ID | 優先度 | 内容 | 状態 | 根拠・確認 |
|---|---|---|---|---|
| QA-001 | P0 | C2Cの近傍グリッド検索で周囲27セルに点がない場合、基準点群を約1000点に間引いて距離を返していた。最近傍が間引き対象なら結果が誤る。 | 修正済み | 厳密3D KD-treeへ変更。総当たり照合50ケースと、2000点の遠方・未サンプル点ケースを追加。 |
| QA-002 | P1 | PLY header欠落、XYZ欠落、未知format、list property、短いASCII行、短いBinary payloadを部分成功として扱い、ゼロ座標や点数減少を発生させ得た。 | 修正済み | 独立パーサで入力を検証し、例外として拒否。ASCII、LE、BE、切詰め、非有限値を回帰テスト。 |
| QA-003 | P1 | PLY/TXTの読み込み・デコードがUnityメインスレッド上で実行され、大きい点群でUIを停止させる。 | 修正済み | `Task.Run`へ移し、進捗・キャンセルを追加。Unity側統合動作は未検証。 |
| QA-004 | P1 | 注釈Undo/Redoの上限処理がStackの列挙順を誤り、最新履歴を落として順序を逆転させ得た。点群切替時も旧スナップショットが残った。 | 修正済み | `BoundedHistory<T>`へ置換し、点群切替時に両履歴を消去。点数不一致時は適用せず破棄。 |
| QA-005 | P1 | GPU buffer更新ごとに全点をCPU走査し、さらに同期`ComputeBuffer.GetData`を実行していた。編集時の待ちとGPU同期停止を招く。 | 修正済み | デバッグ走査・読み戻しを削除。GPUへの全バッファ`SetData`は残るため、部分更新最適化は別計測が必要。 |
| QA-006 | P1 | Pythonが見つからない場合、Unity操作からPythonインストーラをダウンロードし、全ユーザー対象でシステムPATHへ追加していた。 | 修正済み | 無断のシステムインストールを廃止。Pythonは利用者が手動導入し、依存はプロジェクト`.venv`に限定。 |
| QA-007 | P1 | `EditorBuildSettings.asset`の`m_Scenes`が空で、Player buildの起動シーンが登録されていなかった。 | 修正済み | `Assets/VRTestScene.unity`だけを登録。実buildは未実施。 |
| QA-008 | P2 | IMGUIパネル幅は最大460pxまたは画面幅25%だが、一部の入力・ボタンは固定幅。狭いGame Viewで横あふれ・操作しづらさの可能性。 | 未検証 | コード静的確認のみ。800/1280/1920pxでの撮影・実操作が必要。 |
| QA-009 | P2 | 茎径・球径・C2Cの研究上の実測精度に対する独立した真値検証が本監査環境にない。 | 未検証 | 自動テストは内部整合・既知合成データ中心。物理寸法既知の点群で確認が必要。 |

## 適用範囲外

- Scientific algorithmのパラメータや閾値の再設計はしていません。
- 既存measurement JSON、PLYのXYZ/RGB/label仕様、表示倍率・mm解釈を変更していません。
- ライセンス監査に関する作業ツリーの未コミット資料は、今回の変更に含めていません。
