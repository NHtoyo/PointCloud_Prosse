# PointCloudVR (植物点群処理ワークベンチ)

Unity上で数千万点規模の大規模な点群データ（PLY形式等）を描画し、快適なナビゲーションとアノテーション（分類、削除、幾何形状検出等）を行うためのワークベンチです。ノイズ除去などの高度な計算にはPythonのバックエンドを使用しています。

## 別のPCでのセットアップ方法（Git Clone後）

本プロジェクトを別のPCで動作させる場合、点群データなどの大容量ファイルと、Pythonの仮想環境はGitから除外されているため、以下の手順でセットアップを行ってください。

### 1. 必要なソフトウェアのインストール
- **Unity**: Unity Hubから指定のバージョン（6000.4.7f1など）をインストールしてください。
- **Python**: [Python公式サイト](https://www.python.org/) から **Python 3.10以上** をインストールしてください。
  > **【重要】** インストール時の画面で、一番下の **「Add Python.exe to PATH」に必ずチェックを入れてください。**

### 2. 点群データ（PLYファイル）の移行
- Gitにはアップロードされていないため、別のPC等から元データや `PointCloudData` フォルダ等をコピーして持ってきてください。

### 3. Pythonバックエンド環境のセットアップ
ノイズ除去などの機能を動かすためのPython環境を用意します。以下のいずれかの方法でセットアップできます。

#### 方法A: ワンクリックバッチファイルを使用する（推奨）
プロジェクトのフォルダにある **`setup_python_env.bat`** をダブルクリックして実行してください。自動的に仮想環境（`.venv`）を作成し、必要なライブラリ（Open3DやNumPyなど）をインストールします。完了したらUnityを起動してください。

#### 方法B: Unityから自動セットアップする
そのままUnityプロジェクトを開き、シーンを再生（Play）してください。
最初にノイズ除去処理などを実行した際、システムが自動的にPython環境がないことを検知し、裏で自動的にセットアップを行います（画面上にプログレスバーが表示されます）。セットアップ完了後、そのまま処理が開始されます。

## 機能概要と操作方法
- `Assets/VRTestScene.unity` を開いて再生します。
- PC上でのナビゲーション操作は、常に以下の通りです：
  - **左ドラッグ** ＝ カメラ回転（オービット）
  - **右ドラッグ** ＝ カメラ平行移動（パン）
  - **マウスホイール回転** ＝ ズーム

詳細なシステム構造や実装の歴史については、プロジェクト内にある `HANDOVER_DOC.md` を参照してください。
