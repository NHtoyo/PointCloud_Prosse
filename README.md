# PointCloudVR (植物点群処理ワークベンチ)

Unity上で数千万点規模の大規模な点群データ（PLY形式等）を描画し、快適なナビゲーションとアノテーション（分類、削除、幾何形状検出等）を行うためのワークベンチです。ノイズ除去などの高度な計算にはPythonのバックエンドを使用しています。

---

## 🚀 ゼロからの完全セットアップガイド（他のPCで動かすための手順）

新しいPCでこのプロジェクトを動かす場合、Gitからのダウンロードに加えて「Unity」「Python」のインストールと設定が必要です。以下の手順に従えば、誰でも確実に起動までたどり着くことができます。

> ⚠️ **【重要】Python機能を使う場合は、Unityを起動する前に Step 2 の `setup_python_env.bat` を実行してください。**
> 対応するPythonは **3.12.x** です。これを省略すると、ノイズ除去・スケール校正などのPython機能が利用できません。

### Step 1: Gitのインストールとプロジェクトのダウンロード
1. [Git for Windows](https://gitforwindows.org/) にアクセスし、インストーラーをダウンロードしてインストールします（設定はすべて「Next」のデフォルトで構いません）。
2. プロジェクトを保存したいフォルダ（例: `E:\` や `C:\Projects\`）で右クリックし、「**Open Git Bash here**」または「**ターミナルで開く**」を選択します。
3. 以下のコマンドをコピー＆ペーストして実行し、プロジェクトをダウンロード（クローン）します。
   ```bash
   git clone https://github.com/NHtoyo/PointCloud_Prosse.git
   ```

### Step 2: Python環境の自動セットアップ ⬅️ **必須・最初に実行**
1. Step 1 でダウンロードしたフォルダ（`PointCloud_Prosse`）を開きます。
2. その中にある **`setup_python_env.bat`** をダブルクリックして実行します。
3. セットアップはPython 3.12.xが既にインストールされているか確認し、ユーザー領域に仮想環境を作成して、固定バージョンのライブラリをインストールします。Python本体の自動ダウンロードやシステム設定の変更は行いません。
4. Python 3.12がない場合は、案内に従ってPython 3.12を導入してから再実行してください。既存の仮想環境は自動削除・上書きしません。

   > ℹ️ 通常はインターネット接続が必要です。完全なwheelhouseを用意したオフライン導入は `PointCloudVR/python_backend/Setup-Python.ps1` の `-Offline` オプションで行えます。

### Step 3: 点群データ（PLYファイル）のコピー

点群データはファイルサイズが大きすぎるため、Gitにはアップロードされていません。
1. 元のPC、またはUSBメモリなどから、読み込ませたい `.ply` データ（または `PointCloudData` フォルダごと）を、新しいPCにコピーしてください（プロジェクトフォルダ内でも外でも構いません）。

   > ℹ️ `PointCloudData` フォルダはクローン時に自動で作成されます。そこにPLYファイルを入れると便利です。

### Step 4: Unity HubとUnityエディタのインストール
1. [Unity Hub](https://unity.com/ja/download) をダウンロードしてインストールします。
2. Unity Hubを起動し、必要に応じて無料のアカウントを作成・サインインし、Personalライセンスを取得します。
3. 左側の「**Projects**」タブを開き、右上の「**Add**」をクリックします。
4. フォルダ選択ダイアログが開いたら、以下のフォルダを**正確に**選択してください。

   ```
   （クローン先）\PointCloud_Prosse\PointCloudVR
   ```

   例えば `E:\` にクローンした場合は：
   ```
   E:\PointCloud_Prosse\PointCloudVR
   ```

   > ⚠️ **【重要】`PointCloudVR` の中には入らないでください。**
   > `PointCloudVR` フォルダそのものを選択した状態で「フォルダの選択」ボタンを押します。
   > 中にある `test` 等のサブフォルダを選ぶと、空のシーンしか表示されません。

5. 追加されたプロジェクトをクリックすると「エディタバージョンが存在しません」と警告が出るので、**指定されたバージョン（6000.4.7f1）** をインストールボタンから直接インストールしてください。（※モジュールはWindows Build Support等があれば十分です）。

### Step 5: 起動と再生
1. エディタのインストールが完了したら、Unity HubのProjectsタブから **`PointCloudVR`** をクリックして開きます（初回はロードに数分かかります）。
2. Unity が起動したら、画面下部の「**Project**」パネルで `Assets` フォルダを開き、**`VRTestScene`** をダブルクリックしてシーンを開きます。

   > ⚠️ Unity起動直後は空のシーンが表示されることがあります。必ず `VRTestScene` をダブルクリックしてください。

3. 画面上部中央にある **▶（Playボタン）** を押すと、プログラムが実行されます！
4. 画面上の指示に従って点群データを読み込んでください。

## 🎮 基本的な操作方法
再生中の点群ナビゲーション操作は以下の通りです：

- **カメラの回転（オービット）**: `左クリックしたままドラッグ`
- **カメラの平行移動（パン）**: `右クリックしたままドラッグ`
- **ズームイン・アウト**: `マウスホイールを回転`
- **計測やアノテーション時の点の選択**: `マウスの中央ボタン（ホイール）を押し込む` またはツールによる操作

詳細なシステム構造や実装の歴史については、プロジェクト内にある `HANDOVER_DOC.md` を参照してください。
